# dsh-slash-space

**中文** | [English](README.en.md)

中文输入法下，不切英文、不补空格，直接调 skill 和命令。

![输入框工具行左侧的开关](docs/composer-toolbar.png)

## 为什么做这个

调一个 skill，标准动作是四步：

```
切到英文输入法 → 敲空格 → 敲 / → 切回中文
```

先敲空格，是因为 `/` 只有落在行首或空白后面，才会被认成命令。

一天几十次。每一次都在中文打字的中途硬切一刀，节奏断了，注意力也跟着断一次。

而这个动作里，唯一逼你切输入法的，就是那个 `/`。

中文输入法里，`/` 键位打出来是「、」。手指本来就在那儿，那就别切了——让它直接变成「 /」。

省掉的是切输入法和补空格这两步，留下的是同一种打字节奏。上下文填得快一点，也准一点。

## 效果

| 光标前是行首或空白 | 其它情况 |
| --- | --- |
| `/` | ` /` |

打「、」，得到「 /」。

## 为什么偏偏是「、」

中文输入法下 `/` 键输出「、」，这是所有中文输入法的默认行为——不用记新键位，不用改设置。

英文输入法下直接敲 `/`，插件不介入，该怎么打怎么打。

## 兼容

拦的是「插入文本」这个动作，不是键盘按键，所以微软拼音、搜狗、Rime 这些输入法都一样生效。

拼音还在候选框里、没上屏的「、」不会被误伤。

## 开关

输入框工具行左侧有个小开关：左边是轨道和滑块，右边是「/」。

- **开**：按上表替换
- **关**：「、」原样输入
- 状态存在本机，换会话、重开界面都还在

## 安装

```bash
dsh plugin --profile desktop add link:/path/to/dsh-slash-space
```

装完刷新界面。

## 开发

没有构建步骤。`client.js` 就是运行时加载的文件，改完按 `Ctrl+R` 刷新即可。
